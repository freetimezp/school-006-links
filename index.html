01 / UNDERSTANDING LINKS

Every state tells a story.

CSS pseudo-classes let us describe how a link should look depending on what the visitor is doing.

01 :link

Unvisited

The default appearance of a link the visitor has not opened.

Open destination ↗
02 :visited

Visited

A link the browser recognizes as previously visited.

Previously opened ↗
03 :hover

Hover

Activated when a pointer moves over the link.

Move your pointer ↗
04 :active

Active

Visible while the link is being pressed.

Press and hold ↗
i

Remember the order: :link, :visited, :hover, :active. This is commonly remembered as LVHA.

CSS / LINK STATES CSS 
a:link {color: #9b8cff;}

a:visited {color: #c28bff;}

a:hover {color: #ff8c9e;}

a:active {color: #ffffff;}
02 / TEXT DECORATION

Underline with intention.

The text-decoration family gives you control over the line, its appearance, color, and position.

SOLID Creative direction
DASHED Creative direction
DOTTED Creative direction
DOUBLE Creative direction
WAVY Creative direction
THE PROPERTY

text-decoration

A shorthand that controls the line's style, color, thickness, and other decoration details.

line underline / overline / line-through
style solid / dashed / dotted / wavy
color Any valid CSS color
thickness Length or percentage
CSS / DECORATION STYLES CSS 
.link {
    text-decoration-line: underline;
    text-decoration-style: wavy;
    text-decoration-color: #ff8c9e;
    text-decoration-thickness: 2px;
    text-underline-offset: 5px;
}
03 / ACCESSIBILITY

Focus is not optional.

Links should work for everyone, including visitors who navigate with a keyboard instead of a mouse.

KEYBOARD NAVIGATION

Try the Tab key.

Press Tab to move through the links below. The focused link receives a visible outline using :focus-visible.

First destination ↗ Second destination ↗ Third destination ↗
↳

Make focus obvious.

Never remove the browser's focus indicator without providing a clear alternative. 

a:focus-visible {outline: 2px solid #ff8c9e;outline-offset: 5px;}
!

Good practice: Do not rely on color alone to communicate that text is a link. Keep links recognizable through underlines, clear labels, or another visual cue.

05 / PRACTICE

Put it into practice.

Use what you've learned to create a small set of links with clear, polished interaction states.

TASK / 006

Create a navigation menu.

Build a navigation menu with three links. Give each link:

  • A clear default color and underline.
  • A different color and underline on hover.
  • A visible keyboard focus indicator.
  • A pressed appearance using :active.
HINT Remember the LVHA order when writing your CSS.
STARTER CODE HTML + CSS 
<!-- HTML -->
<nav class="navigation">
    <a href="#home">Home</a>
    <a href="#about">About</a>
    <a href="#contact">Contact</a>
</nav>

/* CSS — complete the states */
.navigation a {
    text-decoration: underline;
    text-underline-offset: 4px;
}

.navigation a:link {
    /* Your default style */
}

.navigation a:hover {
    /* Your hover style */
}

.navigation a:focus-visible {
    /* Your focus style */
}

.navigation a:active {
    /* Your active style */
}
