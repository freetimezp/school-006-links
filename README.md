# Lesson 006 — Styled Links, Anchor States & Text Decoration

An interactive beginner-friendly lesson about styling HTML links with CSS.

## Learning Objectives

By completing this lesson, you will understand how to:

- Style HTML anchor elements using CSS.
- Work with the `:link` pseudo-class.
- Understand the `:visited` state.
- Create hover interactions using `:hover`.
- Style pressed links using `:active`.
- Improve keyboard navigation with `:focus-visible`.
- Use the `text-decoration` shorthand.
- Customize underline style, color, and thickness.
- Control underline position using `text-underline-offset`.
- Build accessible and recognizable links.

## Topics Covered

### Anchor States

- `a:link`
- `a:visited`
- `a:hover`
- `a:active`
- `a:focus-visible`

### Text Decoration

- `text-decoration`
- `text-decoration-line`
- `text-decoration-style`
- `text-decoration-color`
- `text-decoration-thickness`
- `text-underline-offset`

### Decoration Styles

- solid
- dashed
- dotted
- double
- wavy
- none

## Interactive Playground

The lesson includes a live CSS playground where learners can:

- Change the decoration line.
- Select different underline styles.
- Choose a custom decoration color.
- Adjust line thickness.
- Change underline offset.
- Preview changes instantly.
- Copy the generated CSS.
- Reset the playground to its default settings.

## Features

- Responsive layout.
- Vanilla HTML, CSS, and JavaScript.
- No frameworks or external JavaScript libraries.
- Interactive examples.
- Live CSS preview.
- Copy-to-clipboard functionality with fallback.
